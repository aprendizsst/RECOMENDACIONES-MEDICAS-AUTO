# Portal SST · Recomendaciones Médicas V10.10

Versión de producción limpia del aplicativo de recomendaciones médicas.

## Incluye
- Motores especializados por formato JER y control periódico.
- Procesamiento masivo de hasta 50 PDF.
- Auditoría con IA y control de calidad.
- Estados `REALIZADO` sin falsos pendientes.
- Salida compacta con exámenes listados solo por nombre y recomendaciones en párrafo cohesivo.
- Vista previa del PDF ajustada al ancho.
- Correo individual o masivo, selección de archivos y envío en PDF, Word o ambos.
- Enrutamiento Google Sheets V10.9: consecutivos y registro SST en archivos separados.
- Tema visual púrpura oscuro premium.
- Despliegue GitHub Pages estático, sin Vite/React/Firebase.

## Backend requerido
`2026.09.04-v10.9-two-sheet-routing`

Los archivos de Apps Script están únicamente en `backend/`.
